# 🍀 Premium Lotto Generator

순수 HTML/CSS/JavaScript로 만든 한국 로또(6/45) 번호 생성기입니다. 별도 설치 없이 `index.html`만 열면 동작합니다.

## ✨ 기능

- 🎲 **다중 게임 생성** — 1·3·5게임(A~E) 동시 추천
- 🚫 **제외 번호** / 📌 **고정 번호** 설정 (입력 검증 포함)
- 💾 **기록 저장** — 브라우저 `localStorage`에 최근 20건 보관
- 📋 **복사** — 게임별 / 전체 복사
- 📊 **통계** — 합계 · 홀짝 · 고저 비율 표시
- 🔔 **효과음** — Web Audio 기반 (파일 불필요, 토글 가능)
- 🌙 **다크 / 라이트 테마** (설정 저장)
- 📱 **모바일 반응형** + ♿ 접근성 지원
- ⌨️ **스페이스바** 단축키로 즉시 생성
- 🎯 한국 로또 **공식 공 색상** 적용

## 🚀 사용법

`index.html`을 브라우저로 열기만 하면 됩니다.

## ⚠️ 안내

모든 번호는 무작위로 생성되며 당첨을 보장하지 않습니다. 재미로만 이용해 주세요.
